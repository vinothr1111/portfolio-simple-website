# Personal Portfolio Website

 A simple and responsive **two-page personal portfolio website** built using **HTML and basic CSS**. This project showcases my personal information, skills, projects, and contact details through a clean and minimal design.

 ## 📌 Pages

 - **Home** – Introduction and a brief overview of my profile.
- **Contact** – Contact information and a simple way to get in touch.

 ## 🛠️ Technologies Used

 - HTML5
- CSS3

 ## ✨ Features

 - Simple and clean user interface
- Two-page website structure
- Responsive layout
- Easy navigation between pages
- Beginner-friendly HTML and CSS implementation

 ## 🎯 Purpose

 This project was created to practice the fundamentals of **HTML, CSS, webpage structure, navigation, and basic responsive design**, while building a simple personal portfolio.
